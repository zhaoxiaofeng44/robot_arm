# myArm — 3D打印肘关节机构 + 三节手指机构 + 整手机构（单指反根验证版）

仿人手臂/手指的双关节直线驱动机构：一台贴臂圆柱直线电机通过一根刚性连杆驱动一个转动关节。
所有关节均为**外购可拆肩螺栓（塞打螺丝）+ 平垫 + 尼龙自锁螺母**，全机一套内六角扳手即可反复拆装。

## 三个模型

| 模型 | 文件 | 构型 |
|---|---|---|
| **肘关节机构 v5** | `arm_mechanism_3d.html` | 上臂(300)固定 + 前臂(250)绕 O 转动 0–120°，电机 A=(28,213)，BD 连杆 85mm，行程 59.393mm |
| **掌+三节手指** | `finger_mechanism_3d.html` | **三个上述单元串联**：掌(300,固定,载电机0) →[关节0/MCP]→ P1 近节(300,载电机1) →[关节1/PIP]→ P2 中节(300,载电机2) →[关节2/DIP]→ P3 远节(250+指尖)；三个关节逐项同方案，安全包络 90°/90°/70° |
| **整手机构** | `hand_mechanism_3d.html` | **五指整手 = 14 个上述单元**：四指各 3 关节 + 拇指 2 关节，机构平面互相平行（指距 70mm）；**反根装配** —— 每指把原指尖段 Pn 当接掌固定段，其远端法兰用 4×M5 固定在 66×10 掌骨板上，自由端（原指根端的掌段）带圆头/防滑垫即现在的指尖；1:1 与手指版同尺寸（整手 1250mm，非人体尺度）；14 关节电机 + **5 台展开/并拢电机**（每指 1 台，侧挂在"接掌段"侧面、轴线沿 y，轴线沿 y、**偏在 z 侧面（z=+30）**、机身 y∈[198,278]，经 R30 曲柄 + 85mm 连杆拉动指根绕 x 摆 ±12°）/ 19 连杆 / **52 组肩螺栓** / 95 打印件 |

浏览器打开 HTML 即可交互（滑杆调角度、播放动画、切换视图/标签/轨迹）。

## v8 扩展（第三个关节：掌指关节 + 掌的联动）

按「关节方式和现有两节一样」把关节数从 2 增到 3，插入点在最根部（掌 ↔ 近节）：

| 项 | 改动前 | 改动后 |
|---|---|---|
| 链条 | 掌件(P1 兼基节) ─O1─ P2 ─O2─ P3 | **掌(固定,载电机0) ─O0─ P1(载电机1) ─O1─ P2(载电机2) ─O2─ P3** |
| 单元 | 2 个（同构） | **3 个（同构）**：P1 与 P2 逐件同几何，打印件可互换 |
| 原有件 | 原 P1 = 基节；原 P2 = 中节 | 原 P1 → **掌段**（前缀 palm/m0/t0，肩螺栓 o0）：本体/指根方块/掌骨法兰/电机/叉耳逐件原样，仅去掉近端被驱动接口（袖套+毂+D侧板，掌为固定根不需要）；原 P2 → **P1 近节**（前缀 p1/m1/t1，肩螺栓 o1） |
| 新增件 | — | **P2 中节 = 原 P2 逐件同几何**（前缀 p2/m2/t2，肩螺栓 o2） |
| 实现 | 两段各自手写 | 抽出通用构造 buildDrivenPhalanx(parent,pfx,segLen,mPfx,tPfx)，P1/P2 各调一次；三个单元的运动学完全独立 |
| 运动学 | getJoints(a1,a2) | getJoints(a0,a1,a2)：P1 绕 O0、P2 绕 O1（相对 P1）、P3 绕 O2，逐级复合到世界系；闭合误差仍 4.3e-14mm |
| UI | 2 滑杆 | **3 滑杆**（θ0 MCP / θ1 PIP / θ2 DIP）+ 预设 0/0/0、45/45/35、90/90/70 + 三关节同比联动 |
| 臂展 | 掌→指尖 864mm | **1164mm**（多一节 300mm 指节；掌段长度由电机+连杆布局决定，与单元同长） |

**新增安全行程包络 90°/90°/70°**：三个关节各自能到 120°，但同时在末端大角度卷曲时指尖会卷回掌段躯体（真实手指同样卷不进掌心）。用 5° 三维网格（0..120° 全组合，15625 姿态）扫出边界后取安全盒，滑杆与演示动画均限制在包络内。

并修掉四处**会骗过校验**的问题：

## 核心设计（v5）

- **BD 连杆 = 等宽长条 100×15×8mm**（R7.5 圆弧端，孔壁 3.2mm）——不再有环眼凸台；
- **全部关节可拆**：O 用 Ø10×26、B 用 Ø8×18、D 用 Ø8×20 肩螺栓 + 自锁螺母，取代 v4 的永久镦铆钉；
- **B 叉头**为独立件：开放双耳 + M6 螺母沉龛夹持桥（螺母坐底板顶面、围壁防转），推杆端部螺纹旋入即完成连接；**拉力靠螺纹副+防转**、压力由底板承担；
- **D 叉耳**为贴前臂侧面的双侧板（位于连杆 z 带之外），消除 v4 跨连杆桥板的实体干涉；
- **电机安装**：前法兰承推（法兰 y[137,141] 顶面 **面接触**安装板底 y=141，4×M4 自下向上）+ 后部 300° 开口抱箍（独立件，**双侧耳板 z=±7..11**，2×M4 贯穿臂身），卸 4 颗螺栓即可轴向抽出电机；
- **轴向浮动 1.0mm/侧**，所有孔轴沿 Z（= 打印方向），抽销后连杆/轴套沿 Z 滑出；
- 手指版机械结构零改动：**同一机构实例化三次**（掌 + 三节指骨），每个被驱动段的近端是上一单元的前臂接口、远端是本单元下级关节的上臂接口，电机安装臂逐级向指尖一侧前移。

## 打印与选型

- 工艺：FDM 0.4mm 喷嘴、层高 0.2mm；孔轴全部沿 Z 竖直免支撑；关节/连杆 100% 填充，臂身 25–40%。
- 材料：指节/叉头/抱箍 PETG 或 PLA+；连杆 PETG/PA-CF；紧固件外购 304 不锈钢。
- 幅面：最大打印件 45° 斜排 ≤ 220mm（手指版最差件 palm_proximal / p1_distal / p2_distal）。
- **执行器选型**：需缸体 ≤80mm、行程 ≥60mm 的紧凑型直线推杆电机（肘版 1 台，手指版 3 台）；整手版按 0.5× 换算为 **Ø20×40mm、行程 ≥30mm、带位置反馈，共 10 只**。
- 连杆为名义刚性概念设计：5kg@250mm 时峰值拉力约 618N，实物需按实际工况重做强度/屈曲/疲劳校核。

## 五指整手的安全行程（目标设计；当前单指模型未启用）

10 只 Ø20×40 电机 + 5 根长指无法在 0–120° 全交叉积上做到零接触，因此整手声明并校验了一个**安全行程包络**：

| 指 | 上限 | 原因 |
|---|---|---|
| 食指 / 中指 / 小指 | **120°** | 全程无干涉 |
| 无名指 | **70°** | 再大时 t2 连杆摆到掌体指根座（首次接触 68°） |
| 拇指 | **45°** | 再大时 P3 远节扫入中指/无名指近节区（首次接触 48°） |

> **上表是旧「0.5× × Z 分层」五指方案的逐指约束，已被现行平行布局取代**：现版五指机构平面平行、间距 70mm（零件 z 向半宽 ≤18mm，相邻指间隙 ≥34mm），`verify_hand.cjs` 三维扫描证实**指间无需额外限位**，四指统一 90°/90°/70°、拇指 90°/70°。详见 `hand_design_spec.md`「安全行程包络」。

> 说明：肘版、手指版、整手版均为 **1:1 机构级几何模型**（`P.scale` 只影响场景显示，不影响 mm 参数）。整手是把同一肘关节单元串成 5 指（四指 3 关节 + 拇指 2 关节 = 14 单元）的开放桁架概念模型，不是人体尺度可穿戴假肢；校验脚本不含绝对尺寸假设，整体等比缩放机构参数即可换尺度。
